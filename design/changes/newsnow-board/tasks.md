# 来源看板实施

- 主题页：按用户决定，用多来源卡片替换原主题列表；不改变站点全局外壳和配色。热门页提供看板入口。
- 参考区域：NewsNow 多来源卡片、榜单标题及独立更新状态、来源选择、关注、热榜与实时分类。保留原始链接和数据来源，不将无发布时间的热榜标成实时。
- 交互：按用户要求默认显示全部来源，滚动接近卡片时读取内容；后台采集独立运行。逐来源重新读取和错误恢复；来源选择与关注保存在本机；实时来源按可用的原始发布时间排序。
- 布局：宽屏自适应多列，窄屏单列；键盘可操作，不增加横向页面滚动。
- 检查：实际浏览器宽屏和手机宽度，检查真实来源、选择、关注、刷新、错误及链接；保留截图和检查结果。
