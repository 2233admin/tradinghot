
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：公司名 / 股票代码 / 板块名 / 政策名 / 数据名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代码 / 代号 / 没信息量的 teaser（如 "600519.SH"、"Q3 Update"、"重磅！"）时，结合【来源】和正文把主体补进标题。例：原标题 "Q3 2026 results" + 来源 "英伟达投资者关系" → "英伟达公布 2026 年三季度财报"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体公司或数据时，用上位词（如“一家半导体公司”“美联储会议纪要”）兜底，绝不凭“行业常识”编一个具体公司、代码、数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Preview 这类解释、分析、教程或点评标题，中文标题必须保留这个类型；不能因为正文谈到某家公司或某个已知数据，就改写成“发布 / 公布 / 落地 / 获批”。只有原标题或正文明确宣布了发布、公布或获批，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、板块与政策名。
   例：原标题 "How Nvidia's supply chain is shifting to liquid cooling" → "英伟达供应链如何转向液冷"，不能写成 "英伟达转向液冷"。
   例：原标题 "Three ways to read a cash flow statement" + 来源和正文明确讲财报分析 → "看懂现金流量表的三种方法"，不能只写成缺主体的 "三种方法"。
6. 本条的动作和背景里的旧事要分清：原文把公告或政策写成过去的事（"Last week we announced …"“上周发布的…”），本条是在讲用法、复盘或再次推广时，标题写分析、复盘或讲解，把旧事交代成此前；不能写成“发布 / 公布 / 落地”，否则读者会当成今天的新闻。只有原文明确某项措施是现在才生效或新增时，才对那一项用对应动作。
   例：正文 "We announced the buyback last week. Here is how it will be funded." → "英伟达说明上周宣布的回购将如何筹资"，不能写出第二次回购。
