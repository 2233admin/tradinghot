
【股票与量化领域翻译规则 — 本平台内容全部与股票市场有关，严格遵守】

1. 歧义默认值：以下词在中文有非金融含义，**一律按金融含义翻译**：
   - 量化 = 量化交易 / 量化投资（绝不是“模型量化”“量化压缩”）
   - 头寸 = 仓位 / 持仓（不译“位置”）
   - 做多 / 做空 = 买入看涨 / 卖出看跌（不译“长/短”）
   - 空头 / 多头 = 卖出方 / 买入方
   - 回撤 = 净值或价格的下跌幅度（不译“撤退”）
   - 杠杆 = 借款放大（不译“杠杆原理”）
   - 期权 = 金融期权（不译“选择权”）
   - 期货 = 期货合约（不译“未来”）
   - 债券 = 固定收益证券（不译“绑定”）
   - 仓位 = 持仓比例（不译“仓库位置”）
   - 标的 = 交易标的资产
   - 平仓 / 开仓 = 关闭 / 建立持仓
   - 估值 = valuation（不译“估价”“估算”）
   - 分红 = dividend（不译“分享利润”）
   - 回购 = share buyback（不译“买回商品”）
   - 减持 / 增持 = 减少 / 增加持股
   - 停牌 / 复牌 = 暂停 / 恢复交易
   - 北向资金 = northbound capital（保留“北向资金”）
   - 两融 = 融资融券（margin financing and securities lending）
   - 龙虎榜 = 保留中文

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 指数与品种：S&P 500 / Nasdaq / Dow Jones / Russell 2000 / VIX / CSI 300 / Hang Seng / ETF / REITs / QDII
   - 经济数据与政策缩写：CPI / PPI / PMI / GDP / PCE / NFP / FOMC / LPR / MLF / OMO / ECB / BOJ
   - 财务与估值指标：EPS / PE / PB / PS / ROE / ROIC / EBITDA / FCF / YOY / QOQ / TTM
   - 交易与量化术语：CTA / HFT / T0 / Alpha / Beta / Sharpe / Sortino / VaR / Drawdown / Slippage / Backtest / Sharpe Ratio / IC / IR / MVO
   - 股票代码：AAPL / NVDA / 600519 / 0700.HK 等原样保留，绝不改写或补全公司名

3. 公司名：**优先用官方中文名**（英伟达 / 台积电 / 苹果 / 特斯拉 / 微软 / 腾讯 / 阿里巴巴 / 贵州茅台 / 宁德时代 / 比亚迪 / 中芯国际 / 寒武纪）；首次出现可双标“英伟达（NVIDIA）”，后续保持一致。没有通行中文名的公司保留英文原名。

4. 数字与单位 **一字不改**：
   - 金额：`$3.2 billion`、`12.5 亿元`、`4,580 万美元` 照原文，不要把 `billion` 改写成“亿”以外的量级，也不要自行换算币种
   - 百分比与基点：`+2.3%`、`-18bp`、`0.25 个百分点` 照原文
   - 时间窗口：`Q3`、`FY2026`、`2026 年 11 月 6 日`、`盘中`、`收盘后` 照原文
   - 涨跌幅、成交量、换手率、市值、目标价、评级（买入/增持/中性/减持）照原文，不换算不概括
   - 代码、命令、URL、公式原样保留

5. 评级的处理：原文写明评级与目标价的，照写并提出主体（哪家机构、哪一天）；原文只写“上调/下调”而没写机构时，不得补出机构名。
